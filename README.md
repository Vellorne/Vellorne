## What we do

VELLORNE designs and builds automation and AI systems for Swiss
companies — the kind of internal tooling that removes repetitive
manual work without handing a company's data to a third party.

- **Automation** — connecting existing tools (ERP, CRM, email,
  documents, internal APIs) so information moves between them
  without manual re-entry.
- **AI agents** — task-specific agents that handle a defined
  workflow (intake, triage, drafting, classification, routing)
  reliably, with a human in the loop where it matters.
- **Private / local AI** — deployments that keep sensitive data
  in-house instead of routing every request to a third-party cloud
  API, for businesses where that matters (legal, medical, financial,
  or simply cautious).
- **RAG & knowledge retrieval** — grounding an assistant in a
  company's own documents instead of relying on a model's general
  training.
- **Integrations** — the unglamorous but essential work of getting
  systems to actually talk to each other.

We start from how a business already works, not from a generic
template, and build around that.

## About this GitHub

This organization hosts small, self-contained technical
demonstrations — one focused idea per repository, real code, real
tests, synthetic data. They show *how* we approach a problem, not
our production systems: client work and our core platform stay
private, for our clients' sake as much as ours.

Every repository includes a README, a license, and (where relevant)
unit tests you can run yourself.
